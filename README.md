# World in Five

An illustrated world-news brief for **25 November 2026**, leading with ESA's first Hera close-ups of the crater on Dimorphos. Four companion stories cover global trade, wartime power outages, human rights and Pacific diplomacy.

## Run

Use Python 3.13; no third-party packages or network are needed.

```sh
python main.py --output-dir ./out
```

Without the option, output defaults to `/output`, or the directory set in `MAKEFUN_OUTPUT_DIR`. The only output is `entry.png`, an exact copy of the bundled artwork.

`design.svg` is the hand-authored source for the image. It uses browser-native vector shapes and system typography, with no external art. Render it in a browser at 1024 × 1024 CSS pixels with device scale 1 and no surrounding margin to recreate the layout.
